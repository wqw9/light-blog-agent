# 为什么是书页

大部分博客是"时间流"，而书是"位置感"。你记得一本书里喜欢的段落在第几章第几页，却很难记住一条动态流里的一篇推送。

所以拾页书阁把每篇文章装订成书：**有章节、有页码、有纸张，还有上一次读到哪里的记忆。**

## 三个设计决定

1. **纸张优先**：米黄底色 + 衬线字体 + 首行缩进，让眼睛先于大脑进入阅读状态。
2. **章节装订**：用 `---` 或一级标题切章，长文不再是一堵墙。
3. **无干扰**：一键沉浸模式，只留下纸张与文字。

## 分章规则

文章上传后会自动分章，优先级从高到低：

| 规则 | 说明 |
|------|------|
| 显式分章符 | 单独一行的 3 个及以上 `-` 或 `*` |
| 一级标题 | 每个 `# 标题` 成为一个新章节 |
| 软分章 | 都没有时，每 2000~3000 字切一章 |

# 阅读器的细节

## 字号

正文默认 16px，可在 15 / 16 / 18 / 20 四档之间调节，偏好保存在本地，下次打开自动恢复。

## 主题

书页提供四套纸张主题，代码高亮配色随之切换：

- **米黄纸**：默认，像旧书
- **纸白**：像新书
- **护眼绿**：像草稿纸
- **夜间**：像深夜台灯下的桌面

## 快捷键

| 按键 | 动作 |
|------|------|
| `←` / `→` | 上一章 / 下一章 |
| `T` | 打开 / 关闭目录 |
| `F` | 沉浸模式 |

## 阅读进度

当前章节的阅读百分比会显示在页面顶部；章节与进度保存在本地，下次打开这篇文章会直接回到上次读到的地方。
