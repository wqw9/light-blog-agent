# 服务器部署与自动部署体系（配置与文档）

**日期**：2026-08-15

## 内容
- **服务器选购建议**：国内轻量（腾讯云/阿里云，需 ICP 备案）vs 香港/海外免备案方案对比、域名解析说明
- **一键初始化脚本 `deploy/setup-server.sh`**：Ubuntu 22.04/24.04 上执行，自动完成系统依赖、Node 22、corepack、pm2、Caddy（自动 HTTPS）、代码拉取、随机管理口令生成、域名配置、防火墙（仅开 22/80/443，后端 3000 不对公网）与首次部署
- **自动部署 `deploy/deploy.sh` + GitHub Actions（`.github/workflows/deploy.yml`）**：向 main 分支推送后自动 SSH 服务器执行「拉取 → 恢复服务器本地配置 → 安装依赖 → 构建 → 数据库同步 → pm2 重启」，支持手动触发
- **服务器本地配置隔离**：`deploy/runtime-config/*.json` 保存服务器上的实际配置（口令哈希、真实域名 CORS、LLM 密钥、关于/小人配置），已 gitignore，每次部署自动恢复，避免被仓库模板覆盖
- **pm2 进程配置 `deploy/ecosystem.config.cjs`**：生产模式、内存上限 300M、自动重启
- **Caddy 模板 `deploy/Caddyfile.example`**：静态前端 + /api 与 /uploads 反代 + gzip
- **部署指南 `deploy/README.md`**：选购表、初始化步骤、GitHub Secrets（SSH_HOST/USER/KEY）配置、上线检查清单、常见问题与回滚
- `.gitattributes`：`*.sh` 强制 LF 换行，避免 Windows 提交导致服务器脚本无法执行

## 提醒
- 上线前记得把服务器上的 `deploy/runtime-config/site.json` 的 allowedOrigins 改成你的域名
- Live2D 模型文件不在仓库里：可选 `scp -r uploads/models/* root@服务器:/opt/myblog/uploads/models/`，否则自动回退默认模型
- 建议定期备份 `data/`、`uploads/`、`deploy/runtime-config/`
