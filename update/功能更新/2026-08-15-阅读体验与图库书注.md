# 阅读体验、图库与书注更新（功能更新）

**日期**：2026-08-15

## 内容

1. **Live2D 模型显示修复（回归修复）**：上一轮安全加固把静态目录收窄为仅 `/uploads/img/`，导致 `/uploads/models/` 下的小人模型 404、回退到 CDN 默认模型。已恢复 models 目录公开静态服务（7 天浏览器缓存），并确认本地模型 model3.json/moc3 可正常加载
2. **上传图片用作头像与封面**：管理页新增「🖼 从图库选」图片选择器（头像与文章封面两个入口），一键从已上传图片中选取，无需手填 URL；原有「上传头像」直接上传仍然可用
3. **书籍搜索**：书架页新增搜索框（书名 / 正文关键字，350ms 防抖），与标签筛选可叠加；服务端搜索沿用参数化查询（安全）
4. **LLM 书籍搜索 Skill**：新增内置 Skill `book-finder`（config/prompts/book-finder.md，含「何时使用」）；聊天面板新增模式切换「💬 闲聊问答 / 📚 书籍搜索」，书籍搜索模式下回答带馆藏引用
5. **语法高亮增强**：代码块补充 `language-*` 类名；主题 CSS 补齐 C#/C++/Rust/Go 等语言的 token 配色（property/operator/constant/char.escape 等）。highlight.js 全量语言本就支持 csharp/cpp（别名 `c#`/`c++` 亦可）
6. **句子书注（允许外部书写）**：读者在阅读页**选中任意句子 → 「💬 写书注」→ 发布注释**，高亮句子点击可查看书注（署名可选）；管理口令持有者可删除。安全设计：仅已发布且非私密文章可写、同 IP 每小时最多 10 条、IP 仅存 SHA-256 哈希、书注内容做长度限制；数据模型新增 `Annotation` 表（随文章级联删除）

## 提醒
