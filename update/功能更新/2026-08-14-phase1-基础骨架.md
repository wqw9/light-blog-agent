# Phase 1 · 基础骨架

**日期**：2026-08-14

## 内容
- pnpm monorepo：`apps/web`（Vue3）、`apps/server`（NestJS）、`packages/shared`、`packages/markdown`
- Markdown 管线：frontmatter 解析、highlight.js 高亮、标题锚点与目录、三级自动分章（`---`/H1/软分章）、字数统计、XSS 防护
- 书页阅读器：纸张布局、4 主题、4 档字号、目录抽屉、上下章、阅读进度、`←/→`/`T`/`F` 快捷键、断点续读、沉浸模式
- 上传模块：拖拽/粘贴/批量、类型白名单、魔数校验、SHA-256 去重、md 上传即发布
- Prisma + SQLite 数据库与种子文章

## 验证
- 建库种子 2 篇（自动分章 3/2 章）
- 章节渲染缓存、上传即发布全链路通过
- 前端生产构建通过（66 模块）

## 备注
- SQLite 不支持 enum/Json：状态用字符串常量
- dev 运行器用 ts-node（tsx 不生成装饰器元数据会破坏 NestJS DI）
- 显式多对多（ArticleTag）嵌套写入需经联接表
