# 标签权限收紧 · 友链 · 全站移动端适配（功能更新）

**日期**：2026-10-22

## 一、标签权限：人编辑标签，AI 只能做「关联」

**目标**：标签库由人完全掌控；LLM 在标签方面只剩一项能力 —— 把标签库里已有的标签关联到文章。

服务端（`apps/server/src/llm/llm.service.ts`）：

- `organize()`（书籍整理）：
  - 先把标签库读出来，作为**唯一可选集合**塞进提示词（`标签库（tags 只能从中原样挑选…）`）
  - 回包里的标签按「去空白 + 忽略大小写」对齐标签库，**只用 `connect`，不再 `connectOrCreate`** —— AI 无法新建 / 改名 / 改色 / 删除标签
  - **只增不减**：文章上已有的人工标签不会被 AI 清掉
  - 返回体新增 `articleTags`（文章当前全部标签）、`ignoredTags`（AI 想用但库里没有的名字，仅提示不入库）、`availableTags`（标签库规模，0 表示得先建库）
- `runSkill()`（Skill 运行生成新文章）：原先把源文章标签 + 硬编码 `'skill'` 一起 `connectOrCreate`，会在库里凭空造出 `skill` 标签；
  现在只沿用**已存在**的标签，`skill` 标记也只在标签库已有同名标签时才打上
- 提示词（`apps/server/src/llm/prompts.ts` 的 `ORGANIZE_SYSTEM` 与 `config/prompts/book-organizer.md`）同步加入「标签规则（最高优先级）」：
  只能从列表原样挑选、禁止发明/改写/翻译/近义替换、库为空就返回 `[]`

前端（管理页）：

- 「标签」页新增**权限说明卡**：标签库全部权能归你，AI 只能关联已有标签
- 文章编辑弹窗新增**标签选择器**：从标签库点选/取消（chip 高亮），仍然可以在输入框手输新标签
- 「🤖 整理」后显示结果提示：关联上哪些标签；AI 想到但库里没有的标签会列出来并说明「已忽略」；标签库为空时直接提示先去建标签

## 二、友链（新增 `/friends`）

- 数据即配置：`config/friends.json`（`title` / `intro` / `applyHint` / `links[]`，每条含 `name` `url` `avatar` `description`）
- 服务端：`GET /api/site/friends`（公开，实时读文件）、`PUT /api/site/friends`（管理口令）
  - `ConfigService.saveFriends()` 走临时文件 + rename；`normalizeFriends()` 双重校验：
    **链接只接受 `http(s)://`**（拦掉 `javascript:` / `data:` 等 XSS 载荷）、头像允许站内 `/uploads/` 或 `http(s)://`、缺名字或缺地址的条目丢弃、最多 100 条
- 前端：新增 `pages/FriendsPage.vue`（卡片墙：头像/站名/域名/简介，点击新窗口打开）+ 路由 `/friends` + 导航项
  （`config/site.json` 的 `nav` 已加「友链」；`AppNavbar` 的兜底导航也同步）
- 管理页新增「友链」标签页：页面文案（标题/说明/交换说明）+ 友链行编辑（上移/下移/删除/新增）、头像可从图库选
  （图片选择器新增 `friendAvatar` 目标）；保存后立刻生效，非法地址会被服务端丢弃并在页面提示原因

## 三、全站移动端适配

- **导航**：`≤760px` 折叠为汉堡菜单（下拉面板，点条目 / 路由变化 / Esc 自动收起；桌面端保持横排，导航过长时自身横向滚动）
- **基础样式**（`styles/base.css`）：移动端容器内边距收窄、`-webkit-text-size-adjust`、iOS 下背景改 `scroll`、
  输入框统一 16px（避免聚焦缩放）、页脚加 104px 底部留白防浮钮压字
- **页面**：首页 hero 用 `clamp()` 缩放且主按钮通栏；书架卡片单列 + 标签筛选横向滑动；归档元信息换行；
  统计卡片两列、图表降高、排行榜换行；关于页头像/字号收缩；阅读页书名 `clamp()`、章节导航按钮等宽、书注表单改为底部弹出
- **浮动组件**：阅读工具栏移动端改为底部横条（左右让开小人控制钮与问答/关于按钮，实测无重叠）；
  小人缩放窄屏封顶 0.5x（`MascotHost` 视口监听 + 有效缩放）；聊天抽屉整屏、输入行贴底安全区；关于名片左右贴边
- **管理页**：标签栏横向滚动、表单行纵向排列、弹窗（编辑/图库）整屏化、按钮通栏、供应商行单列
