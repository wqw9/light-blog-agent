# 红队渗透测试与安全加固（修复记录）

**日期**：2026-08-15

## 一、测试范围与方法

将本项目作为本地靶场（http://127.0.0.1:3000），以"无任何口令的外部攻击者"视角执行黑盒攻击，结合白盒源码审查验证。攻击目标：私密文章、草稿、管理口令、聊天记录、LLM API Key 等敏感数据。

## 二、确认的漏洞（均已修复）

| 编号 | 严重度 | 漏洞 | 攻击实证 |
|------|--------|------|----------|
| V1 | 🔴 严重 | **空口令=开放模式**：未设置管理口令时，所有管理接口（增删改文章/上传/LLM 配置/Skill/标签）无鉴权可用 | 无口令 POST /api/articles 返回 201，直接创建草稿/私密文章 |
| V2 | 🔴 严重 | **私密文章无访问控制**：`private` 仅对 AI 生效，列表/详情/章节/搜索对所有人公开 | 无口令读取私密文章章节内容（TOP-SECRET 正文） |
| V3 | 🔴 严重 | **草稿可枚举可读**：`?status=all` 无需口令，草稿详情/章节 200 | 无口令拉取全量列表含 DRAFT，读草稿章节内容 |
| V4 | 🟠 高危 | **聊天会话无鉴权**：列表/详情（含完整消息）/删除全部公开 | 无口令读取用户全部历史对话内容 |
| V5 | 🟠 高危 | **LLM baseUrl → SSRF + API Key 外泄**：任意 URL 可用，密钥随 Bearer 头发往攻击者服务器 | 无口令改配置指向本地监听器，触发测试连接后捕获 `Authorization: Bearer SK-…` |
| V6 | 🟡 中危 | **统计泄漏**：排行暴露私密文章标题；总览暴露草稿数/上传数 | 刷 3 次阅读后排行出现私密文章标题 |
| V7 | 🟡 中危 | **上传原始文件公开可下载**：md/pdf/docx 直链暴露 storedPath | 无口令获取上传记录中的 storedPath |
| V8 | 🟡 中危 | **阅读量可刷**：无鉴权无限制 POST /view | 3 连发全部 201，排行被操纵 |
| V9 | 🟡 中危 | **聊天接口无鉴权无限流 + 消息数组无上限**：可烧 token 预算 | 100 条消息数组被接受 |
| V10 | 🟢 低危 | **CORS 兜底策略过宽**：allowedOrigins 未配置时反射任意来源（当前配置已限制，属纵深防御项） | 预检验证：现配置下 evil 源已被拒绝 |
| V11 | 🟢 低危 | **admin.json 损坏时 fail-open**；llm/usage、llm/status 信息泄漏 | 白盒确认 |

**验证为安全的项**：Markdown XSS 防护（script/img onerror/javascript: 链接全部转义或拦截）✅；/uploads 路径穿越（4 种编码均 404）✅；上传魔数校验/扩展名白名单/SHA-256 去重 ✅；scrypt 口令哈希 + AES-256-GCM 密钥加密 ✅；Prisma 参数化查询（无 SQL 注入）✅；Skill 文件名白名单（无路径穿越写入）✅。

## 三、修复内容（平衡安全与易用）

1. **V1/V11 认证 fail-closed**（auth/admin.guard.ts、auth/admin-check.ts、auth/password.ts、auth/rate-limiter.ts）：
   - 未配置口令时管理接口返回 **503 + 设置指引**（不再"空口令=开放"）；配置文件损坏同样拒绝
   - 明文口令比较改为常量时间比较（safeEqual）；限流器参数化（口令 5 次/10 分钟、聊天 20 次/分钟、阅读 3 次/小时）
   - 新增 AdminCheckService：公开接口按请求身份分流可见内容，不计入登录限流
2. **V2/V3 文章可见性**（article.service/controller）：公开口径强制 `status=PUBLISHED + private=false`；私密/草稿的详情与章节对非管理员返回 404（不泄露存在性）；`status=all` 未授权直接 401
3. **V4 会话鉴权**（llm.controller）：会话列表/详情/删除与用量统计全部要求管理口令；前端 ChatPanel 游客不再请求历史（也不弹口令框）
4. **V5 LLM baseUrl 校验**（config.service）：仅 http/https；http 明文仅允许 localhost/127.0.0.1/::1（自托管场景），远程一律 https；校验失败返回 400
5. **V6 统计脱敏**（stats.service）：草稿数/上传数/标签数/本月新增仅管理员可见；排行、热力图、月度趋势排除私密文章
6. **V7 上传受控下载**（main.ts、uploads.controller）：静态目录只公开 `/uploads/img/`；md/pdf/docx 走 `GET /api/uploads/files/:name`（口令 + 文件名白名单 + 防穿越）
7. **V8 阅读计数限流**（article.service）：同 IP 同文章每小时最多计 3 次
8. **V9 聊天加固**（llm.controller）：每 IP 20 次/分钟；消息数组上限 30 条；总长度上限 12000 字符；删除不存在会话返回 404
9. **V10 CORS 兜底**（main.ts）：allowedOrigins 未配置时回退本地开发地址并打印警告（不再反射任意来源）
10. **其他**：安全响应头（nosniff/SAMEORIGIN/Referrer-Policy）、移除 X-Powered-By、标签颜色白名单校验、view 接口对不存在文章静默返回

## 四、修复后复验结果（黑盒）

- 无口令：创建/status=all/会话/用量/上传记录 → 全部 401；未配置口令时 → 503
- 口令爆破：第 6 次错误 → 429；正确口令即时清零
- 私密/草稿：未授权详情+章节 404、搜索 0 命中、排行不含；管理员正常可见
- 上传文件：未授权下载 401、静态直链 404、授权下载 200
- LLM baseUrl：内网 http → 400；远程 https → 200
- 聊天：第 21 次连发 → 400；31 条消息 → 400
- 阅读计数：4 连发只计 3；标签非法颜色 400；CORS evil 源预检拒绝；XSS 转义回归通过

## 五、剩余风险与建议（权衡后保留）

- 聊天会话无"归属"概念（单用户设计）：知道 sessionId 可向他人会话**追加**消息（不可读取/删除）。个人单用户场景风险低；如未来多用户需加 owner 绑定
- 管理口令仍为共享口令模式（无独立会话/无 2FA）：个人博客的易用性取舍；口令强度建议 12+ 位
- 对话接口保持公开可用（博客问答是产品功能），依赖限流 + 每日 token/花费上限兜底
- 部署前**必须设置管理口令**：`config/admin.json` 的 password（首次启动自动转哈希）或环境变量 `MYBLOG_ADMIN_PASSWORD`

# 第二轮：常见渗透工具模拟回归测试

**日期**：2026-08-15（同日第二轮）

## 一、方法

模拟 sqlmap / nikto / dirb / hydra / ffuf / nuclei 等工具的行为，对已加固版本做回归攻击。目标实例：用户真实运行中的开发服务（:3000，只读黑盒探测）+ 隔离副本实例（:3001 + 独立数据库 + 注入测试口令，可执行写操作与爆破）。

## 二、测试结果（全部通过 ✅）

| 工具模拟 | 测试内容 | 结果 |
|---------|---------|------|
| sqlmap | q/tag/page/pageSize/sort/id/slug 注入 30+ 载荷（`' OR 1=1`、UNION、注释、LIKE 通配） | 全部无害：200/400/404，无数据泄漏、无报错回显 |
| nikto/dirb | 24 个敏感路径（/.git、/.env、/config、/data/*.db、secret.key、模型目录、编码穿越） | 全部 404 |
| hydra | 30 次口令爆破 + **X-Forwarded-For 轮换** | 401×4 → 429×26；XFF 无法绕过（不信任代理头，按真实 IP 限流） |
| ffuf | 数组参数污染（q[]/tag[]/page[]…） | 曾致 500（已修），无信息泄漏 |
| nuclei | 安全响应头、X-Powered-By、OPTIONS/TRACE/方法覆盖 | 头齐全、TRACE 404、方法覆盖被守卫拦截 401 |
| XSS 进阶 | svg/onload、math+mXSS、data:/vbscript:/javascript: 链接、大小写混淆 | 全部转义或拒链，无执行上下文 |
| 上传滥用 | HTML 冒充 md（含 script）、exe 伪装 md、文件名 `../../` 穿越 | HTML 渲染转义；exe 被魔数拒绝；穿越被 sanitize |
| SSRF 绕过 | baseUrl 数字 IP 记法（2130706433/0x7f000001/127.1/0177.0.0.1）、userinfo、%00、IPv6 映射 | 数字记法被 URL 规范化为 127.0.0.1（本属回环放行，非绕过）；非回环数字目标（3232235777=192.168.1.1）与其余变种全部 400 |
| 限流绕过 | 聊天 21 连发 + XFF 轮换；阅读计数 4 连发 + XFF 轮换 | 第 21 次 400；计数封顶 3 |
| IDOR | sessions/usage/uploads/files 无口令访问 | 全部 401 |

## 三、新发现与修复

| 编号 | 严重度 | 问题 | 修复 |
|------|--------|------|------|
| R2-1 | 🟢 低 | 公开标签列表的计数包含私密/草稿文章 → 泄露隐藏文章的标签与存在性（如某标签公开 0 篇但 count=1） | tags.controller：公开口径只统计 `status=PUBLISHED + private=false` 的文章关联；管理员可见全量 |
